# Dataset

This project uses the official UCI Devanagari Handwritten Character Dataset (dataset 389): 92,000 32×32 grayscale PNG images, 46 classes, split by the publisher into `Train/` (85%) and `Test/` (15%). UCI lists the dataset under CC BY 4.0. The dataset is not committed to Git.

The original official archive is `https://archive.ics.uci.edu/static/public/389/devanagari+handwritten+character+dataset.zip`. Extract it here so this path exists:

`data/DevanagariHandwrittenCharacterDataset/Train/`
