Evaluation evidence

Scope and responsible use: AksharCoach classifies isolated handwritten characters. The local demo can also process a plain page of separately spaced handwritten symbols. It is not printed-chart, word, sentence, or paragraph OCR; softmax scores are model scores, not calibrated probabilities.

See the full implementation, report, source data attribution, and viva notes in the GitHub repository.
